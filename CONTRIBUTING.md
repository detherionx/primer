# Contributing

This repository is public. Treat every tracked file as publishable.

- Use synthetic learners in tests and evals.
- Do not commit `.env`, credentials, or real transcripts.
- Prefer a failing eval over an untested teaching heuristic.
- Read `AGENTS.md` and `project/invariants.yaml`.
- Open issues as falsifiable units (“detect repeated misconception across sessions”), not platform epics.

There is no open-source license yet. Do not add one unless Carmelito (and later Edwin) explicitly decide to.
